# baro-calltrack

Скрипт для сайтов BARO: определяет, откуда пришёл посетитель (SEO / Google Ads / Google Maps / ChatGPT /
Facebook / Instagram / Other), и при нажатии на номер телефона отправляет это в таблицу звонков.
Личных данных посетителя не собирает.

Подключение на сайте (WPCode → Header & Footer → Footer):

```html
<script src="https://cdn.jsdelivr.net/gh/ustinovivan822822/baro-calltrack@v1/baro-calltrack.js" defer></script>
```
